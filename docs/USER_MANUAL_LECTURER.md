# Moderated Learning Management System
## Lecturer User Manual

**Version:** 1.0.0  
**Application:** Moderated Learning Management System (LMS)  
**Intended user:** Lecturer

---

## 1. Introduction

This manual explains how lecturers use the Moderated Learning Management System (LMS) to manage course assignments, set deadlines, grant deadline extensions, view student submissions, and assess submitted work.

Lecturers can only perform these activities for courses assigned to them.

## 2. Accessing the System

1. Open the LMS application on the school computer.
2. Enter your lecturer username.
3. Enter your password.
4. Follow the displayed prompts to access the lecturer menu.

Your account must have the Lecturer role.

## 3. Lecturer Menu

The lecturer menu provides six functions:

1. My courses.
2. Create an assignment.
3. List assignments of a course.
4. Grant a deadline extension to a student.
5. View submissions for an assignment.
6. Mark or re-mark a submission.

Select the required option and follow the prompts.

## 4. Viewing Assigned Courses

1. Select **My courses**.
2. The system displays the courses assigned to your lecturer account.
3. Review the course IDs and details.

If no courses are displayed, contact the system administrator to verify your course assignment.

## 5. Creating an Assignment

1. Select **Create an assignment**.
2. Select the relevant course from your assigned courses.
3. Enter the assignment title.
4. Enter a description, if required.
5. Enter the assignment deadline.
6. Enter the maximum mark.
7. The system displays the assignment ID when creation succeeds.

**Important:** Check the deadline and maximum mark carefully before creating the assignment.

## 6. Listing Course Assignments

1. Select **List assignments of a course**.
2. Select the relevant course.
3. The system displays the assignments belonging to that course.

The displayed information includes:

- Assignment ID
- Assignment title
- Deadline
- Maximum mark

Use the assignment ID when viewing submissions or granting extensions.

## 7. Granting a Deadline Extension

A lecturer can grant an individual student an extended deadline for an assignment.

1. Select **Grant a deadline extension to a student**.
2. Select the relevant course.
3. Select the assignment.
4. Enter the student's user ID.
5. Enter the new deadline for that student.
6. Provide a reason for the extension. The reason must contain at least five characters.
7. The system confirms when the extension has been granted.

Ensure that the correct student and assignment have been selected before submitting the extension.

## 8. Viewing Student Submissions

1. Select **View submissions for an assignment**.
2. Select the relevant course.
3. Select the assignment.
4. The system displays the submissions associated with that assignment.

Review the available submission information before proceeding with marking.

## 9. Marking or Re-marking a Submission

1. Select **Mark or re-mark a submission**.
2. Select the relevant course.
3. Select the assignment.
4. Review the displayed submissions.
5. Enter the submission ID to be marked.
6. Review the displayed student name, submission status and maximum mark.
7. Review the available submission file versions.
8. Check whether a late penalty applies.
9. Enter the raw mark before the late penalty.
10. Enter written feedback.
11. If the submission has already been marked, provide a reason for changing the mark.
12. The system saves the mark and confirms the operation.

### Important marking information

- The raw mark must be within the permitted range, from zero to the assignment's maximum mark.
- Written feedback is required.
- When changing an existing mark, a reason for the change is required.
- The system displays the applicable late penalty where one exists.
- The lecturer's saved mark remains hidden from the student until the Head of Department releases it.

## 10. Understanding the Mark Release Process

The LMS uses a moderation process to ensure that marks are reviewed before students can see them.

The general workflow is:

1. Student submits assignment.
2. Lecturer assesses the submission and records a mark and feedback.
3. Head of Department reviews and moderates the mark.
4. Head of Department releases the mark.
5. Student can then view the released result.

**Remember:** Saving a mark does not automatically make it visible to the student.

## 11. Good Practices for Lecturers

- Confirm that you are working with the correct course.
- Provide clear assignment titles and descriptions.
- Set accurate assignment deadlines.
- Check student submissions before marking.
- Apply the displayed late-penalty information appropriately.
- Provide meaningful written feedback.
- Give a valid reason when changing an existing mark.
- Verify marks before saving them.
- Follow the departmental moderation and release process.

## 12. Troubleshooting

| Problem | Recommended action |
|---|---|
| No courses are displayed | Contact the administrator to verify your course assignment. |
| A course has no assignments | Create an assignment or verify that the correct course was selected. |
| No submissions are displayed | Confirm the selected assignment and check whether students have submitted work. |
| Incorrect assignment selected | Return to the course and select the correct assignment. |
| Mark exceeds the maximum mark | Check the assignment's maximum mark and enter a valid raw mark. |
| Existing mark is being changed | Provide the required reason for changing the mark. |
| Student cannot see a saved mark | Contact the Head of Department regarding moderation and release. |

For persistent technical problems, contact the designated system technician.

## 13. Conclusion

The lecturer is responsible for managing assignments, reviewing student submissions, assessing work and providing feedback. The moderation process ensures that marks remain subject to Head of Department review before being released to students.
