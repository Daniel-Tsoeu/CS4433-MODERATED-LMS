# Moderated Learning Management System
## Student User Manual

**Version:** 1.0.0  
**Application:** Moderated Learning Management System (LMS)  
**Intended user:** Student

---

## 1. Introduction

This manual explains how students use the Moderated Learning Management System (LMS) to access enrolled courses, view assignments, submit or resubmit coursework, and check their results and lecturer feedback.

The system provides a central platform for managing coursework submissions and accessing released academic results.

## 2. Accessing the System

1. Open the LMS application on the school computer.
2. Enter your student username.
3. Enter your password.
4. Follow the displayed prompts to access the student menu.

Your account must have the Student role and must be enrolled in the relevant courses.

## 3. Student Menu

The student menu provides four functions:

1. My courses.
2. View assignments of a course.
3. Submit or resubmit an assignment.
4. My submissions, marks and feedback.

Select the required option and follow the displayed instructions.

## 4. Viewing Enrolled Courses

1. Select **My courses**.
2. The system displays the courses in which you are enrolled.
3. Review the displayed course information.

If no courses appear, contact the administrator to verify your enrolment.
