# Moderated Learning Management System
## Administrator User Manual

**Version:** 1.0.0  
**Application:** Moderated Learning Management System (LMS)  
**Intended user:** System Administrator

---

## 1. Introduction

This manual explains how an administrator uses the Moderated Learning Management System (LMS) to manage user accounts, academic departments, courses, lecturer assignments and student enrolments.

The administrator is responsible for maintaining the system's user and academic configuration.

## 2. Accessing the System

1. Open the LMS application on the school computer.
2. Enter the administrator username.
3. Enter the administrator password.
4. Follow the displayed prompts to access the administrator menu.

Only an account with the Administrator role can access administrator functions.

## 3. Administrator Menu

The administrator menu provides the following functions:

1. Create user account.
2. List user accounts.
3. Update a user's name or e-mail.
4. Deactivate / reactivate an account.
5. Reset a user's password.
6. Create department.
7. List departments.
8. Create course.
9. List courses.
10. Assign lecturer to a course.
11. Enrol student in a course.
12. View recent mark audit log.

Select the required menu option and follow the prompts displayed by the application.

## 4. Managing User Accounts

### 4.1 Creating a User Account

1. Select **Create user account**.
2. Choose the required role:
   - 1 – Student
   - 2 – Lecturer
   - 3 – Head of Department
   - 4 – Administrator
3. Enter the username.
4. Enter the user's full name.
5. Enter an e-mail address, if available.
6. For a student, enter the student number.
7. For a lecturer or Head of Department, select the relevant department ID.
8. Enter an initial password.
9. Repeat the password for confirmation.
10. The system displays the newly created user's ID if successful.

**Important:** Ensure that the selected role and the supplied details are correct before creating the account.

### 4.2 Listing User Accounts

1. Select **List user accounts**.
2. The system displays a table containing:
   - User ID
   - Username
   - Full name
   - Role
   - Student number, where applicable
   - Account status

Use the user ID when performing other account-management operations.

### 4.3 Updating User Details

1. Select **Update a user's name or e-mail**.
2. Review the displayed user list.
3. Enter the ID of the account to update.
4. Enter the new full name.
5. Enter the new e-mail address.
6. Leave the e-mail field blank if you intend to clear the existing e-mail address.
7. The system confirms when the account has been updated.

### 4.4 Deactivating or Reactivating an Account

1. Select **Deactivate / reactivate an account**.
2. Review the user list.
3. Enter the relevant user ID.
4. Confirm whether the account should be activated.
   - Enter `y` to activate the account.
   - Enter `n` to deactivate the account.
5. The system displays a confirmation message.

Deactivation does not delete the user's existing records.

### 4.5 Resetting a User's Password

1. Select **Reset a user's password**.
2. Review the user list.
3. Enter the relevant user ID.
4. Enter the new password.
5. Repeat the password.
6. The system confirms the reset if both entries match and the operation succeeds.

Inform the affected user through the school's approved communication channel.

## 5. Managing Departments

### 5.1 Creating a Department

1. Select **Create department**.
2. Enter the department code, for example `MCS`.
3. Enter the department name.
4. The system displays the department ID when creation succeeds.

### 5.2 Listing Departments

1. Select **List departments**.
2. The system displays a table containing:
   - Department ID
   - Department code
   - Department name

Keep the department ID available when creating courses or assigning departmental users.

## 6. Managing Courses

### 6.1 Creating a Course

1. Select **Create course**.
2. Review the displayed department list.
3. Enter the department ID to which the course belongs.
4. Enter the course code, for example `CS4433`.
5. Enter the course title.
6. Enter the academic year.
7. The system displays the course ID when creation succeeds.

### 6.2 Listing Courses

1. Select **List courses**.
2. Review the displayed course information.
3. Identify the correct course before assigning lecturers or enrolling students.

## 7. Assigning Lecturers to Courses

1. Select **Assign lecturer to a course**.
2. Review the course list.
3. Enter the required course ID.
4. Review the user list.
5. Enter the lecturer's user ID.
6. The system confirms the assignment if successful.

Check that the selected account belongs to the intended lecturer.

## 8. Enrolling Students in Courses

1. Select **Enrol student in a course**.
2. Review the course list.
3. Enter the required course ID.
4. Review the user list.
5. Enter the student's user ID.
6. The system confirms the enrolment if successful.

Verify the course and student IDs before submitting the operation.

## 9. Viewing the Mark Audit Log

1. Select **View recent mark audit log**.
2. The system displays up to the 50 most recent mark-audit records.
3. Review the available records when monitoring mark-related activities.

The audit log supports accountability and monitoring of mark-related operations.

## 10. Good Administrative Practices

- Create accounts using accurate user information.
- Assign users the correct roles and departments.
- Confirm course details before creating courses.
- Verify lecturer and student IDs before making assignments.
- Deactivate accounts when access should no longer be available instead of deleting records.
- Handle password resets through approved school procedures.
- Review mark-audit records when monitoring academic administration.
- Protect administrator login credentials.

## 11. Troubleshooting

| Problem | Recommended action |
|---|---|
| Password confirmation does not match | Re-enter the password and confirmation carefully. |
| Incorrect user ID | Review the user list and use the correct ID. |
| Incorrect department ID | Display the department list and verify the ID. |
| Incorrect course ID | Display the course list and verify the ID. |
| An operation is rejected | Review the entered information and the system's error message. |
| Unable to access administrator functions | Confirm that the account has the Administrator role. |

For persistent technical problems, contact the designated system technician.

## 12. Conclusion

The administrator maintains the LMS's user accounts and academic configuration. Accurate account creation, departmental organisation, course setup and enrolment management help ensure that lecturers, Heads of Department and students can use the system correctly.
