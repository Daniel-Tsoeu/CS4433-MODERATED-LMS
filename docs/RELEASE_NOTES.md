**Release date:** 3 November 2026  
**Release type:** Initial release  
**Version:** 1.0.0

---

## 1. Release Overview

Version 1.0.0 is the initial release of the Moderated Learning Management System (LMS), a C++17 console-based application designed to support the management of academic assignments, student submissions, assessment and departmental mark moderation.

The release provides role-based access for four categories of users: Administrators, Lecturers, Heads of Department and Students.
